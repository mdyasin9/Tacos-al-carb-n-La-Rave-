# Tacos al carbón “La Rave” — Demo website

এটি একটি স্ট্যাটিক ওয়েবসাইট ডেমো। মোবাইল, ট্যাবলেট ও কম্পিউটারে কাজ করার জন্য তৈরি; Spanish/English ভাষা বদলানো যায়; menu category filter, WhatsApp order link, phone link, Google Maps embed/directions এবং supplied image assets আছে।

## কীভাবে চালাবেন
1. ZIP ফাইল Extract করুন।
2. `index.html` ফাইল ব্রাউজারে খুলুন (সেরা ফলের জন্য সব ফাইল একই ফোল্ডার কাঠামোয় রাখুন)।
3. GitHub Pages-এ দিতে হলে repository-এর root-এ `index.html` ও `assets` ফোল্ডারসহ সব ফাইল upload করুন; তারপর **Settings → Pages → Deploy from a branch → main → /(root) → Save** নির্বাচন করুন।
